# Documentation assets

Store public, sanitized screenshots and diagrams here.

Before adding an image:

1. Use the built-in synthetic/demo workspace when possible.
2. Remove usernames, absolute paths, repository names, prompts, secrets, and customer data.
3. Confirm that browser chrome, notifications, and unrelated windows are not captured.
4. Prefer PNG for UI screenshots and SVG for diagrams.
5. Use descriptive lowercase names such as `overview.png` or `run-replay.png`.
6. Review the final committed bytes; do not rely only on best-effort app redaction.

## README tour

`harness-lens-tour.gif` is a 31.6-second, 960×600, five-frames-per-second
tour assembled from the three reviewed English synthetic screenshots below. It
shows, in order:

1. Harness inventory and the Defined / Resolved / Observed / Evaluated evidence boundary.
2. Metadata-only Codex run replay.
3. Saved-to-Saved Harness snapshot comparison.

Regenerate it from the repository root with:

```bash
sh scripts/generate-demo-gif.sh
```

Generation requires `ffmpeg`. The script does not open the desktop app or
capture the screen; it only reads the versioned synthetic PNG files. Before
committing a regenerated GIF, inspect its start, both transitions, and final
screen, then confirm that each source PNG still contains synthetic data only.
The same source bytes and ffmpeg build generate stable output; different ffmpeg
versions may encode palette details differently.

To refresh the source frames, build the current checkout, open its browser-only
synthetic demo at a 1440×900 viewport, and capture Overview, Runs, and Compare
after each view is stable. Confirm that the visible workspace is the generated
`/Users/developer/Projects/mobile-app` example, the page says `Synthetic demo`,
Compare is enabled, and the browser console has no warnings or errors. Save the
frames as real PNG bytes (not a JPEG with a `.png` suffix), then run the script
above. This source-frame capture is intentionally review-gated because an
automated screen recorder could silently publish stale or sensitive UI.
